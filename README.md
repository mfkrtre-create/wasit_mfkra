# تجربة الإدخال العقاري الذكي

تطبيق MVP مبني بـ Next.js لاختبار إدخال الرسائل العقارية العربية من النص أو الصوت، ثم تحويلها إلى بيانات منظمة قابلة للمراجعة والتعديل قبل الاعتماد.

## المتطلبات

- Node.js 20 أو أحدث
- npm
- مفتاح Groq API
- مفتاح Google Gemini API

## التثبيت

```bash
npm install
```

## إعداد البيئة

أنشئ ملف `.env.local` في جذر المشروع:

```bash
GROQ_API_KEY=ضع_مفتاح_Groq_هنا
GEMINI_API_KEY=ضع_مفتاح_Gemini_هنا
```

لا تستخدم `NEXT_PUBLIC_` مع مفاتيح Groq أو Gemini لأنها يجب أن تبقى على الخادم فقط.
لا يوجد أي دعم لقراءة المفاتيح من ملفات بديلة. إذا ظهر أي مفتاح قديم في ملفات نشر أو أرشيفات، اعتبره مخترقاً وأنشئ مفتاحاً جديداً قبل التشغيل.

## الحصول على مفتاح Groq

1. افتح لوحة Groq.
2. أنشئ API key من إعدادات الحساب.
3. ضع المفتاح في `.env.local` داخل `GROQ_API_KEY`.

يستخدم التطبيق نموذج `whisper-large-v3-turbo` لتحويل الصوت العربي إلى نص.

## الحصول على مفتاح Gemini

1. افتح Google AI Studio.
2. أنشئ Gemini API key.
3. ضع المفتاح في `.env.local` داخل `GEMINI_API_KEY`.

يستخدم التطبيق نموذج Gemini سريع يدعم الإخراج المنظم. يمكن تغيير النموذج بإضافة:

```bash
GEMINI_MODEL=gemini-3.6-flash
```

## التشغيل المحلي

```bash
npm run dev
```

ثم افتح:

```bash
http://localhost:3000
```

## النشر على Vercel

1. ارفع المشروع إلى GitHub.
2. أنشئ مشروعاً جديداً في Vercel.
3. أضف متغيرات البيئة:
   - `GROQ_API_KEY`
   - `GEMINI_API_KEY`
   - `GEMINI_MODEL` اختياري
4. انشر المشروع.

قبل إطلاق الإنتاج يجب ضبط SMTP موثوق للدعوات، استعادة كلمة المرور، OTP، وإشعارات البريد. التشغيل المحلي لا يتوقف على SMTP.

## سير العمل

1. الصق رسالة عقارية عربية أو سجّل رسالة صوتية من المتصفح.
2. عند التسجيل، يرسل المتصفح الملف إلى `/api/transcribe`.
3. route handler يرسل الصوت إلى Groq Whisper ويرجع النص العربي.
4. النص يرسل إلى `/api/extract-property`.
5. route handler يطلب من Gemini استخراج JSON مطابق للمخطط.
6. الخادم يتحقق من النتيجة مرة أخرى باستخدام Zod.
7. الحقول تمتلئ تلقائياً وتبقى قابلة للتعديل.
8. يراجع المستخدم البيانات ثم يضغط `اعتماد البيانات`.
9. يظهر JSON النهائي المعتمد دون حفظه في قاعدة بيانات.

## أمثلة اختبار

نص عرض عقاري:

```text
للبيع أرض سكنية في حي العارض بمدينة الرياض، المساحة 450 متر، شارع 20 متر، واجهة شمالية، السعر مليون و350 ألف صافي، رقم ترخيص الإعلان 123456، والتواصل على الرقم 0501234567.
```

مثال صوتي:

```text
عندي طلب عميل يبي فيلا في شمال الرياض ويفضل حي الياسمين أو النرجس، أربع غرف أو أكثر، والميزانية إلى مليونين ومئتين ألف.
```

## أخطاء شائعة

- `مفتاح Groq غير مضبوط`: تأكد من وجود `GROQ_API_KEY` في `.env.local` وأعد تشغيل السيرفر.
- `مفتاح Gemini غير مضبوط`: تأكد من وجود `GEMINI_API_KEY` في `.env.local` وأعد تشغيل السيرفر.
- رفض الميكروفون: اسمح للمتصفح باستخدام الميكروفون ثم حاول مجدداً.
- صيغة صوت غير مدعومة: استخدم متصفحاً يدعم WebM أو سجلاً بصيغة mp3 أو wav أو m4a.
- فشل استخراج JSON: جرّب نصاً أوضح، وتحقق من صلاحية مفتاح Gemini والنموذج المستخدم.

## قرارات MVP المثبتة

- المصادقة ستكون بالدعوات فقط في MVP، مع ترك التصميم قابلاً لاحقاً للتسجيل العام أو التسجيل عبر كود إحالة.
- سيضاف حقل timezone إلى ملفات المستخدمين عند بناء المصادقة، والافتراضي `Asia/Riyadh`.
- البحث والفلاتر التقليدية تسبق البحث بالذكاء الاصطناعي.
- روابط المشاركة العامة و `/s/[token]` مؤجلة للمرحلة الثانية إلا إذا أصبحت لازمة لتدفق المشاركة المعتمد.
- ميزات AI search المتقدمة، التقارير المتقدمة، والإحالات لا تؤخر المصادقة، العروض، الطلبات، إدخال AI، الخرائط، العملاء، التذكيرات، الإشعارات، المشاركة الأساسية، سلة المهملات، الحاسبة، الأمان، والنشر.
